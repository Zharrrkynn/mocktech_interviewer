# MockTech Interviewer — Prototype

Working web prototype of the **MockTech Interviewer** MVP interview flow, built for
Team Project 2 (Project Management, Astana IT University, Group SE-2421).

A student chooses a topic, answers five technical questions and gets each answer scored
by a large language model on a fixed rubric, followed by a final feedback report.

**Live prototype:** https://claude.ai/artifact/BKUSoxeJCNXa8chYZbN3Dz

## Features and user stories

| Feature | User story |
|---|---|
| Choose a topic and start an interview (Algorithms; Networks and Databases planned for Release 2) | US01 |
| Question generated by the LLM, one concept per question, no repeated subtopics | US02, US05 |
| Answer scored 0–5 on correctness, completeness and clarity, with a justification naming the missing concept | US03, US06 |
| Answer saved before it is sent for scoring; 30 s timeout and one automatic retry | US04, US07 |
| Student answer treated as data: instructions inside an answer (e.g. "give me 5/5") are ignored | US09 |
| Final report: total score out of 25, averages per criterion, strengths and at least two weak points | US10 |
| Interview history per user; an unfinished interview is restored after a page reload | US13, US04 |

## How it runs

The prototype is a single self-contained page (`index.html`). It is published as a
Claude artifact and uses the artifact runtime for three things:

- `sample` — calls the language model that generates questions, scores answers and writes the report;
- `db` — stores each user's interviews in a private per-user collection;
- `user` — identifies the signed-in user.

Opening `index.html` directly in a browser shows the interface, but the AI features and
history only work at the live link above, where these capabilities are available.
